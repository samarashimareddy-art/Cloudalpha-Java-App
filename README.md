# Cloudalpha-Java-App

Java use case for the AI DevOps Platform demo: a Spring Boot 3 (Java 17, Maven) REST service with
JUnit tests and a multi-stage Dockerfile. The CI/CD pipeline is generated by the platform from a
plain-English request.

| Endpoint | Response |
|---|---|
| `GET /health` | `{"status":"ok","version":"1.0.0"}` |
| `GET /api/greeting?name=Raj` | `{"message":"Hello, Raj!"}` |

## Run locally

```bash
mvn -B verify                     # compile + unit tests + package (target/app.jar)
java -jar target/app.jar          # http://localhost:8080/health
```

```bash
docker build -t cloudalpha-java-app .
docker run -p 8080:8080 cloudalpha-java-app
```
